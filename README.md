# Binary System Medical — binarysys.net

Bilingual (English + Arabic, RTL) website for **Binary System Medical Co. (BSM)**, an
SFDA-certified Saudi distributor of IVD, medical-device and research-use-only solutions.
Built from scratch by Glint Sites as a static site for **Cloudflare Pages**, replacing the
previous WordPress/Elementor site.

## Quick reference

| What | Where |
|---|---|
| Company details, stats, social links | `site.config.json` |
| Products (23, EN + AR) | `content/products.json` |
| Manufacturers / brands (20, EN + AR) | `content/brands.json` |
| Divisions & disciplines (IVD / MD / RUO) | `content/taxonomy.json` |
| Insights articles (EN + AR) | `content/insights.json` |
| Page templates | `scripts/pages/*.mjs` |
| Header, footer, `<head>` | `scripts/lib/layout.mjs` |
| Shared components (cards, plate, forms…) | `scripts/lib/components.mjs` |
| Styles / behaviour | `css/site.css`, `js/site.js` |
| Form endpoint | `functions/api/contact.js` → `functions/_shared/contact-handler.js` |

**Never hand-edit the generated `.html` files** — edit the content/templates and rebuild.
Also generated by the build: `css/site.min.css` (edit `css/site.css`), `sitemap.xml`, and the
`script-src` hashes in `_headers` (the CSP allows exactly the inline scripts the pages ship).

## Build & run

```bash
npm run build      # regenerates all 78 pages, sitemap.xml, css/site.min.css and the CSP hashes; checks every link
npm run dev        # wrangler pages dev . — serves with Functions, _headers and _redirects
npm test           # 98 tests: form handler security, page SEO/a11y basics, hreflang, CSP, hidden internals, microplate
npm run qa         # headless-Chrome checks against the dev server: overflow, accessibility, language switch
npm run deploy:preview   # uploads a clean clone of HEAD to a Cloudflare Pages preview (commit first)
npm run images     # after adding images: writes the -xs/-md responsive variants (Pillow)
python -I scripts/brand-assets.py   # only if the logo changes: favicon, app icons, OG images
```

Node 22+ and no npm dependencies (Python + Pillow only for image scripts). The build fails on
unknown brands, missing images, missing translations, broken internal links or anchors.
Restart `npm run dev` after a rebuild that changes `_headers` (wrangler reads it at startup).

## Adding a product

1. Add `images/products/<slug>.webp` (≈1400px) and `<slug>-sm.webp` (≈720px).
2. Add an entry to `content/products.json` with `brand`, `division`, `discipline`, `fit`
   (`contain` for cut-out shots on white, `cover` for photos) and `en` / `ar` copy.
3. `npm run images` (writes the small `-xs` card variant), then `npm run build`.

## Two languages, one site

Every page exists in English and Arabic (RTL) on its own URL (`/about` ↔ `/ar/about`), each with a
self-canonical, reciprocal `hreflang` (en, ar, x-default) and sitemap alternates — so search engines
index both. Switching language is designed to feel instant and continuous:

- **Prerendered:** speculation rules prerender the other-language page on hover, so the switch is instant in Chromium browsers.
- **Animated:** a cross-document View Transition dissolves one language into the other while the logo and the hero plate glide to their mirrored positions.
- **Same place:** the reader lands on the same section and scroll position, and a parser-inserted `rel=expect` holds the first frame until that position is set.
- **Nothing lost:** half-typed forms (kept 12 h in local storage, cleared on send), the quote list and catalogue filters carry over.
- **Arrives settled:** the hero plate, counters and reveals don't replay after a switch.
- **Language hint:** visitors whose browser prefers the other language get a one-time, dismissible suggestion. There is no redirect, which would hurt SEO.
- **Arabic typography:** IBM Plex Sans Arabic is scaled about 6% larger. Latin names that end in ™, ® or + get a left-to-right mark so they render correctly inside Arabic text.

## Design notes

- **Brand colour** `#683F99` from the logo; deep ink-violet `#150E24` for dark sections; a mint
  "signal" accent used sparingly.
- **The microplate** (home hero): a 96-well ELISA plate whose 12 columns are 8-bit ASCII
  bytes (rows A–H) spelling `BINARYSYSTEM`. Section labels A–H on the home page follow the
  plate rows.
- **The B-mark composition**: photos clipped to the two lobes of the logo's "B"
  (`bmark()` in `components.mjs`).
- Fonts are self-hosted (OFL): Archivo, IBM Plex Mono, IBM Plex Sans Arabic.
