## Cloudflare Pages setup

- **Build command:** none (generated HTML is committed). **Output directory:** `/`.
- **Functions compatibility date:** `2025-01-01`.
- No `wrangler.toml` — keep env vars in the dashboard. For local dev, put them in a gitignored `.dev.vars`.

| Variable | What it does | Type | Status |
|---|---|---|---|
| `ALTCHA_HMAC_KEY` | Signs the spam-check challenge. 64-char hex: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` | Secret | [ ] Not set |
| `WEB3FORMS_ACCESS_KEY` | Emails each lead to BSM via web3forms.com (register it with the inbox that should receive leads, e.g. info@binarysys.net) | Secret | [ ] Not set |
| `CONTACT_WEBHOOK_URL` | **Alternative** to Web3Forms: https endpoint (Zapier / Make / n8n / CRM) that receives each lead as JSON | Secret | [ ] Not set |

Set **one** destination. Without one, forms show a "please call or email us" error instead of
dropping the lead. Env-var changes apply to new deployments only — redeploy after setting them.

Forms: `/contact` (topic select, `?topic=partnership` pre-selects) and `/quote` (includes the
visitor's quote list). Both POST to `/api/contact` with an ALTCHA proof-of-work token, honeypot,
same-origin check and per-IP rate limit. Without JavaScript the form still posts and redirects to
`/thank-you` (or `/ar/thank-you`).

## Quality checks done (Nov 2026)

- **Accessibility (WCAG 2.1 AA):** contrast, names and labels, keyboard (the mega menu follows its trigger; the drawer traps focus), 24px targets (44px on touch), 3:1 field borders, reduced motion, 200% reflow, label-in-name.
- **Lighthouse (local dev server):** Accessibility, Best Practices and SEO are 100 on every page tested. Performance is 97–100 on desktop and 84–91 on mobile, with CLS ≤ 0.002. Production adds Cloudflare compression and HTTP/3.
- **Security:** the CSP has no `unsafe-inline` for scripts. ALTCHA tokens are single-use, signatures are compared in constant time, bodies are capped at 64 KB, and the rate-limit map is pruned.
- **Responsive:** every page in both languages is checked at 320 and 768 px with no horizontal overflow, and the key pages at 1440 px.

## Site-specific notes

- Product images come from the old site, at full resolution, converted to WebP (`images/products/<slug>.webp` + `-sm.webp`).
- Partner logos are in `images/partners/`. BDR, GeneProof, Vircell, Blue-Ray and Jena are official SVGs. Jena and Tianlong only publish white logos, so a one-colour dark version is used.
- The quote list is stored in the visitor's `localStorage` (`bsm-quote-v1`) and sent only with the quote form.
- No third-party scripts, cookies or analytics. The CSP in `_headers` reflects that.
